# Portfólio

Esqueleto de site de portfólio em HTML, CSS e JavaScript puros, sem dependências.

- `index.html`: estrutura e conteúdo
- `style.css`: visual (a cor de destaque fica em `--acento`)
- `main.js`: loader, cursor, menu e animações de rolagem
- `assets/`: coloque aqui `curriculo.pdf`, `resume.pdf` e imagens

Para ver localmente, abra o `index.html` no navegador.
